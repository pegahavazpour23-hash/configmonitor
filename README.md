# Config Monitor — مانیتور کانفیگ‌های v2ray برای اندروید

هر ۲۰ ثانیه کانفیگ‌ها و آدرس‌های دلخواه (مثل `google.com`) را چک می‌کند. اگر یکی بیش از ۵ بار پشت‌سرهم
جواب نداد، الرت تمام‌صفحه با صدا و لرزش نشان می‌دهد؛ حتی در حالت سایلنت، تا دکمه‌ی **«متوجه شدم»** را بزنی.

**هیچ VPN یا تونلی روی گوشی ساخته نمی‌شود.**

## تغییرات نسخه ۲
- نام برنامه **Config Monitor** و شناسه‌ی داخلی `app.configmonitor` (برنامه‌ی جدا؛ نسخه‌ی قبلی `app.vlessmonitor` را اگر نصب کرده‌ای دستی پاک کن)
- پروتکل‌ها: **VLESS، VMess، Trojan، Shadowsocks، SOCKS، Hysteria2، WireGuard**؛ نوع لینک خودکار تشخیص داده می‌شود
- افزودن با **اسکن QR** (دوربین یا عکس از گالری) و **لینک ساب** (subscription)
- **سوییچ روشن/خاموش** روی هر کانفیگ، «توقف همه / فعال‌سازی همه»، حذف با کشیدن ردیف و **بازگردانی (Undo)**
- **انتخاب زنگ الرت**: ۴ زنگ داخلی، زنگ‌های سیستم یا فایل صوتی دلخواه، پیش‌شنوایی، بلندی صدا، لرزش و شروع تدریجی
- صفحه‌ی **جزئیات** هر مورد: نمودار تأخیر، آپ‌تایم، آخرین خطا، تاریخچه‌ی قطع و وصل، «تست همین الان»، کپی لینک و نمایش QR
- فیلتر (همه / قطع / کند / متوقف)، جستجو و مرتب‌سازی
- موشن‌های نرم (گذر بین صفحه‌ها، جابه‌جایی ردیف‌ها، حلقه‌ی وضعیت، شمارش تأخیر) و تنظیم «کاهش انیمیشن»
- مجوز «نمایش روی سایر برنامه‌ها» اختیاری شد
- **کلید امضای ثابت**: هر APK جدید روی قبلی نصب می‌شود و نیازی به پاک‌کردن نیست

## ساخت APK

### روش ۱ — GitHub Actions (بدون نصب هیچ برنامه‌ای)
1. در github.com یک repository **خصوصی** بساز (کلید امضا داخل پروژه است؛ repository را عمومی نکن).
2. تمام محتویات این پوشه را (از جمله پوشه‌ی مخفی `.github`) آپلود کن. در مک: `Command + Shift + .` فایل‌های مخفی را نشان می‌دهد.
3. تب **Actions** ← **Build APK** ← **Run workflow**.
4. بعد از چند دقیقه فایل **ConfigMonitor-debug-apk** را دانلود کن؛ داخل zip فایل `app-debug.apk` است.

### روش ۲ — Android Studio
1. پوشه را Open کن (SDK 35 را خودش نصب می‌کند).
2. هسته و فونت‌ها را بگیر: `bash scripts/fetch-assets.sh` (در ویندوز: Git Bash)، یا دستی `libv2ray.aar` را از
   <https://github.com/2dust/AndroidLibXrayLite/releases> در `app/libs/` و فونت‌های `Vazirmatn.ttf`، `Inter.ttf`،
   `JetBrainsMono.ttf` را در `app/src/main/assets/fonts/` بگذار.
3. **Build ← Build APK(s)**؛ خروجی: `app/build/outputs/apk/debug/app-debug.apk`

> بدون `libv2ray.aar` برنامه بیلد می‌شود ولی فقط TCP چک می‌کند (بنر هشدار می‌دهد؛ Hysteria2 و WireGuard بدون هسته تست نمی‌شوند).
> بدون فونت‌ها از فونت سیستم استفاده می‌شود.

## نصب
- اجازه‌ی «نصب از منابع ناشناس» را بده. اگر Play Protect هشدار داد: **More details ← Install anyway**.
- اولین بار این برنامه به‌عنوان «برنامه‌ی جدید» نصب می‌شود؛ بعد از آن هر APK جدید روی قبلی نصب می‌شود.

## بعد از نصب (مهم)
1. **تنظیمات ← مجوزها**: اعلان‌ها، نمایش تمام‌صفحه روی قفل و «بدون محدودیت باتری» را فعال کن. «نمایش روی سایر برنامه‌ها» اختیاری است ولی الرت را فوری‌تر باز می‌کند.
2. روی شیائومی / سامسونگ / هوآوی / اوپو در تنظیمات خود گوشی «Autostart» یا «Never sleeping apps» را هم برای برنامه روشن کن.
3. اگر گوشی همیشه روی شارژ باشد، پایدارتر کار می‌کند.
4. اگر Do Not Disturb روی «بدون هیچ وقفه» است، آلارم‌ها را در DND مجاز کن.

## نحوه‌ی کار
- هر مورد شمارنده‌ی جدا دارد؛ با هر موفقیت صفر می‌شود. الرت روی خطای **ششم** (بیشتر از ۵) می‌آید، یعنی حدود ۲ دقیقه.
- بعد از «متوجه شدم» برای همان مورد الرت تکراری نمی‌آید تا دوباره وصل و دوباره قطع شود.
- مراحل چک کانفیگ: DNS با خود اندروید ← اتصال TCP (شکست سریع؛ فقط پروتکل‌های TCP) ← تست واقعی از مسیر کانفیگ با هسته‌ی xray.
  تست واقعی یک نمونه‌ی موقت xray بدون هیچ inbound می‌سازد، یک درخواست می‌فرستد و می‌بندد.
- آدرس‌های دستی هم چک می‌شوند و مرجع‌اند: اگر همه‌ی آدرس‌ها هم قطع باشند، الرت می‌نویسد «احتمالاً اینترنت گوشی قطع است».
- هر تست روی اکانت ترافیک و اتصال ثبت می‌کند؛ بهتر است برای مانیتور از اکانت اختصاصی استفاده کنی.

## محدودیت‌ها
- ترنسپورت‌های `mKCP`، `h2` و `quic` و لینک‌های Shadowsocks با `plugin` و Hysteria2 با `obfs` پشتیبانی نمی‌شوند (در لیست «پشتیبانی نمی‌شود» می‌آیند و الرت نمی‌دهند).
- TUIC، ShadowTLS و AnyTLS هسته‌ی دیگری (مثل sing-box) می‌خواهند و فعلاً نیستند.
- Hysteria2 با `insecure=1` بدون `pinSHA256` تست نمی‌شود؛ `allowInsecure` در TLS با اثر انگشت گواهی جایگزین شده است.
- نتیجه‌ها از مسیر اینترنت خودِ همین گوشی هستند، نه از دید مشتری‌ها.
- آپ‌تایم از لحظه‌ای که مانیتورینگ روشن شده حساب می‌شود.
